# CLAUDE.md

Clinic AI Platform lets EU/EEA clinics (ADR-0020) answer patient messages in seconds using an
AI assistant grounded in that clinic's own data. It turns those conversations into
booked appointments instead of a human receptionist doing it manually.

What is proven instead: credentials were verified during provisioning; the bucket is private; CORS was verified by reading it back; there is no lifecycle rule; both endpoints return 401 unauthenticated in production; migration 0014's privilege state was verified (SELECT and INSERT true, UPDATE and DELETE false, RLS and FORCE RLS unchanged); at the time of #79, 319 tests plus typecheck, lint, build and format:check were green; and the presigned Content-Type signature binding is covered by a regression test. docs/operations/production-rebuild-runbook.md is written but has never been executed or rehearsed.

Backups are not proven. A complete logical backup has not been demonstrated with the current database role and RLS configuration: under FORCE ROW LEVEL SECURITY, a role without BYPASSRLS may fail to dump protected tables or, with `--enable-row-security`, dump only the rows it can access, potentially omitting data. Production recovery therefore currently relies on Render's point-in-time recovery (3-day window). No restore of production has been tested, and backup completeness remains unassessed. A read-only restore-check tool exists only locally (not in this repository); it is not approved for use against production, Render or a PITR copy, and its passing is not evidence that a backup is complete. A local restore rehearsal (2026-10-19, synthetic data, physical copy) and its restore-check v10.3 results are recorded in `docs/operations/restore-drill-plan.md`; the Render PITR drill (Phase 3 there) has not started.

## Hard rules

- Nothing gets built before the roadmap phase that calls for it.
- No ADR changes status (Proposed → Accepted, etc.) without a human comment in the
  pull request saying so.
- Humans merge. Agents open pull requests; they never merge them.
- No real patient or clinic data anywhere — not in the repo, fixtures, issues, Notion,
  or an AI prompt.
- A one-way-door decision gets its own ADR, with Ahmed's approval, before code.
