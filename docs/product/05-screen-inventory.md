# Screen Inventory

"Phase" is the earliest roadmap phase ([`docs/03-roadmap.md`](../03-roadmap.md)) whose acceptance
criteria require the screen to exist. Entries marked **(inferred)** are this document's judgment
call, not something the roadmap states explicitly — see
[`00-overview.md`](./00-overview.md#contradictions-and-gaps-flagged-not-silently-resolved).

| Route                              | Purpose                                                                        | Primary action              | Roles allowed                                      | Empty state                                                                           | Error state                                         | Phase                                        |
| ---------------------------------- | ------------------------------------------------------------------------------ | --------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------- | -------------------------------------------- |
| `/`                                | Explain the product, drive sign-up                                             | Start sign-up               | Public                                             | N/A (static)                                                                          | N/A (static)                                        | P0 (done)                                    |
| `/privacy`                         | State data handling and patient-data policy                                    | None (read only)            | Public                                             | N/A (static)                                                                          | N/A (static)                                        | Pre-launch (cross-cutting)                   |
| `/login`                           | Staff authentication                                                           | Sign in                     | Public                                             | N/A                                                                                   | "Invalid email or password"                         | P2                                           |
| `/invite/[token]/accept`           | Let an invited staff member activate their account                             | Accept invite, set password | Public, gated                                      | N/A                                                                                   | "This invite link is no longer valid"               | P2                                           |
| `/dashboard`                       | At-a-glance summary of today's work                                            | Navigate to today's work    | owner, admin, practitioner, receptionist           | "No activity yet"                                                                     | "Couldn't load your overview" + retry               | P0 (stub) → P2 (functional)                  |
| `/dashboard/conversations`         | List active and past patient conversations                                     | Open a conversation         | owner, admin, practitioner, receptionist           | "No conversations yet"                                                                | "Couldn't load conversations" + retry               | P3                                           |

Reply: owner, admin, receptionist  | N/A (always ≥1 message)                                                               | "Message failed to send" + retry                    | P3                                           |
| `/dashboard/patients`              | Look up a patient and their history                                            | Open a patient's record     | owner, admin, practitioner, receptionist           | "No patients yet"                                                                     | "Couldn't load patients" + retry                    | P3 (inferred)                                |
| `/dashboard/patients/[id]`         | View one patient's contact info and history                                    | Start conversation / book   | owner, admin, practitioner, receptionist           | "No conversation or appointment history yet"                                          | "Couldn't load this patient" + retry                | P3 (inferred)                                |
| `/dashboard/appointments`          | View the clinic's schedule                                                     | Book / reschedule / cancel  | View: all four. Manage: owner, admin, receptionist | "No appointments scheduled"                                                           | "Couldn't load the schedule" + retry                | P4                                           |
| `/dashboard/appointments/new`      | Book a new appointment                                                         | Confirm booking             | owner, admin, receptionist                         | N/A (form)                                                                            | "That slot is no longer available — choose another" | P4                                           |

Edit: owner, admin, receptionist   | N/A                                                                                   | "Couldn't update this appointment" + retry          | P4                                           |

| `/dashboard/staff`                 | Manage who has access to the clinic's account                                  | Invite a staff member       | owner, admin                                       | "Only you have access — invite your team"                                             | "Couldn't load staff list" + retry                  | P2                                           |
| `/dashboard/staff/invite`          | Send a staff invitation                                                        | Send invite                 | owner, admin                                       | N/A (form)                                                                            | "Couldn't send invite" + retry / "Already invited"  | P2                                           |
| `/dashboard/settings/clinic`       | Set clinic profile (hours, services, prices) used by booking and the assistant | Save changes                | owner, admin                                       | N/A (pre-filled at sign-up)                                                           | "Couldn't save changes" + retry                     | P1 (data) / P2 (editable once authenticated) |

Every screen with a role-restricted primary action also defines what a role outside its allowed
list sees when it reaches the route directly (e.g. a stale link, or manually typing a URL); see
[`06-acceptance-criteria.md`](./06-acceptance-criteria.md), which states that behavior per screen
rather than repeating it in this table.
