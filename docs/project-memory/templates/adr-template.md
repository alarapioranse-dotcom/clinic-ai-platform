# ADR Template

Canonical version: [`docs/adr/README.md`](../../adr/README.md). This file is a convenience copy
for starting a new record; if the two ever differ, `docs/adr/README.md` wins and this copy is
corrected to match it.

```markdown
# NNNN — Title

## Status

Proposed | Accepted | Superseded by NNNN

## Date

YYYY-MM-DD

## Phase

Which roadmap phase (see `docs/03-roadmap.md`) this decision belongs to.

## Context

What problem forces this decision, and what constraints bound it.

## Decision

What was decided, stated plainly enough to act on.

## Consequences

What this makes easier, what it makes harder, and what it forecloses.

## Alternatives considered

What else was on the table, and why it lost.
```
